This module extends account_liquidity_forecast by including purchase orders not yet invoiced.
It uses the Expected Arrival Date (date_planned) from purchase order lines.
You can also choose to include draft purchase orders (RFQs) by enabling the "Include draft PO" option.

To launch the report wizard, navigate to Accounting/Invoicing > Reporting > Liquidity Forecast.
A configuration wizard will open, allowing you to define the parameters for the report.
