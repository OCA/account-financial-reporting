This module extends the four OCA financial reports — **General Ledger**,
**Journal Ledger**, **Open Items**, and **Aged Partner Balance** — with
an optional **Analytic Tags** column.

When the *Show Analytic Tags* checkbox is enabled in the report wizard,
every journal item row shows the analytic tags attached to that move
line, placed immediately after the *Analytic Distribution* column. The
extra column is rendered in both the PDF and XLSX outputs.

For the Aged Partner Balance report the column only appears when *Show
Move Line Details* is also active, because analytic tags are a property
of individual journal items, not of partner-level aggregates.

Configuration
=============

No additional configuration is required after installation.

The *Show Analytic Tags* checkbox appears automatically in each
supported report wizard, next to the existing *Show Analytic
Distribution* / *Show Analytic Account* option. It is enabled by
default.

Usage
=====

Open any of the supported report wizards:

- **Accounting → Reporting → General Ledger**
- **Accounting → Reporting → Journal Ledger**
- **Accounting → Reporting → Open Items**
- **Accounting → Reporting → Aged Partner Balance**

In the wizard form, tick **Show Analytic Tags** and generate the report.
An *Analytic Tags* column will appear to the right of the *Analytic
Distribution* column, listing the tags assigned to each journal item.

.. note::

   For the Aged Partner Balance report, the *Analytic Tags* checkbox is
   only visible when **Show Move Line Details** is also enabled. When
   move line details are hidden the tags column is suppressed
   automatically, as there are no individual journal items to annotate.
