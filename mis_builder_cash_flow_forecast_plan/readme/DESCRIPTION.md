This module extends `mis_builder_cash_flow` so you do not have to create recurring cash flow forecast lines one by one.

It adds:

- Forecast categories: that can be assigned to any cash flow forecast line, so forecast lines can be grouped and filtered (e.g. by rent).
- Cash flow plans: a recurring template that generates a whole series of forecast lines with a single click.
- A per-company, configurable limit on the number of forecast lines a single plan can generate at once, to avoid runaway series over very long date ranges.
